# Ступень: учебный центр digital-профессий

Сайт учебного центра с AI-ассистентом. Ассистент отвечает на вопросы о курсах, ценах и расписании по документам центра (RAG): ищет подходящие фрагменты в локальной папке и формирует ответ через Claude API со ссылками на файлы-источники.

Стек: Next.js 16 (App Router) + TypeScript, Tailwind CSS 4, Motion, локальные эмбеддинги `Xenova/multilingual-e5-small` через transformers.js, Claude API (`claude-opus-5-5`).

## Запуск

```bash
npm install
cp .env.example .env      # вписать ANTHROPIC_API_KEY
npm run dev               # http://localhost:3000
```

Тесты и проверка типов:

```bash
npm test
npm run typecheck
```

## Документы для ассистента

1. Положите файлы центра в папку `documents/` (можно с подпапками). Поддерживаются `.md`, `.txt`, `.pdf`, `.docx`.
2. Обновите базу знаний: кнопка «Обновить базу» в чате (видна в режиме разработки) или команда `npm run index`.
3. Изменённые файлы пересчитываются по хэшу, неизменённые пропускаются, удалённые убираются из индекса.

Индекс хранится в `data/index.json`, модель эмбеддингов кэшируется в `.cache/models` (скачивается один раз, около 120 МБ). Обе папки создаются автоматически и в git не попадают.

Если документов нет или в них нет ответа, ассистент так и говорит и предлагает оставить заявку. Цены и даты он не выдумывает.

## Заявки

Форма «Записаться» сохраняет заявки в `data/leads.jsonl`. Отправку в CRM или на почту подключим отдельным шагом.

## Известные особенности Windows

- **Visual C++ Redistributable.** Локальная модель работает на onnxruntime, которому нужен Microsoft Visual C++ Redistributable 14.40 или новее. Со старой версией модель аварийно завершается (ошибка `0xC0000005`). Сайт при этом продолжает работать, а ассистент сообщает о проблеме. Решение: установить последнюю версию «Microsoft Visual C++ Redistributable» x64 с сайта Microsoft и перезапустить `npm run dev`.
- **Сборка через webpack.** Turbopack в Next 16 падает на кириллице в пути к проекту (`Новая папка\ахат`), поэтому `dev` и `build` запускаются с флагом `--webpack`.

## Устройство

```
app/api/chat        вопрос → поиск фрагментов → потоковый ответ Claude (NDJSON)
app/api/documents   GET: список документов; POST: переиндексация (локально без токена, в продакшене с REINDEX_TOKEN)
app/api/leads       заявки на обучение
lib/rag/source.ts   интерфейс источника документов
lib/rag/loader.ts   LocalFolderSource: чтение папки documents/
lib/rag/indexer.ts  синхронизация индекса с источником
lib/rag/embed.ts    эмбеддинги в отдельном процессе (embed-worker.mjs)
lib/rag/answer.ts   промпт и вызов Claude
```

## Следующий шаг: Google Drive

Новый источник реализует интерфейс `DocumentSource` из `lib/rag/source.ts` и добавляется в список `sources` в `lib/rag/knowledge-base.ts`. Индексер, поиск и чат при этом не меняются: документы из Drive хранятся в том же индексе с пометкой `source: "google-drive"`.
